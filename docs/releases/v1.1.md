## 修复

针对 #1 反馈的实拍取色偏亮、电子图片有误差的问题（#2）：

- **点白校准时自动锁定曝光、白平衡与对焦**。此前点白后移到样品上，相机自动曝光会重新调亮画面，导致读数偏亮。光线或构图变化后，可在 ⋮ 菜单中解锁并重新点白。
- **拍照后进入测量页沿用取景页的白平衡增益和取色框**，不再被重置。
- 修复取景页硬件白平衡设置实际不生效的问题，白平衡统一在软件中计算。
- 拍摄保存的图片改为 **PNG 无损**格式，避免 JPEG 压缩改变读数。
- 导入图片统一按 **sRGB** 解码（带 Display P3 等配置文件的图片会先转换到 sRGB）。

## 说明

- 点白会把白色归一到 (255, 255, 255)，读数整体会比不做校准的软件偏亮，属于预期行为；是否改为「只校正色偏、保持亮度」见 #3。
- JPEG 为有损格式，不同软件解码同一张 JPEG 可能相差 ±1～2，需要精确比对时请使用 PNG。
- 1.0 与 1.1 的实拍读数不宜直接比较，建议同一批实验使用同一版本。

## 安装

下载下方 `ColorGrabber-v1.1.apk` 安装，可直接覆盖升级 1.0，历史记录会保留。

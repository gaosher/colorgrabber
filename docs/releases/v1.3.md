## 新功能

### 参考白模式（取景页）

⋮ 菜单 →「参考白模式」开启后，黄色取色框右侧会出现一个**白色虚线小框**：

1. 把试管放在黄框里，小框对准旁边的白背景。
2. App 会**每一帧**用小框里的白色重新校准。样品和参考白在同一帧里测量，补光强弱、相机自动曝光的变化会被自动抵消，**无需点白、无需锁定**。
3. 白平衡一行显示状态：
   - 「参考白 ✓」：已校准
   - 「参考白稳定中 n/5」：参考白合格，正在确认（约 1 秒）
   - 「参考白⚠过曝 / 偏暗 / 不均匀」：小框位置不合适，此时沿用上一次的增益，请调整构图

开启期间「点白校准」按钮停用；退出后保留当前增益。拍照后测量页沿用拍照时的增益。

### 取色时自动剔除离群像素（取景页、测量页）

取色框内亮度明显偏离的像素（少量气泡、反光点、管壁边缘）会被自动排除，不再拉偏平均值。过曝提示和白点质量检查仍按框内全部像素判断。

## 说明

- 离群像素剔除会让读数比 1.2 更接近溶液本身的颜色。**同一批实验请使用同一版本**，1.2 与 1.3 的读数不宜直接比较。
- 参考白模式归一化目标与点白一致（白 = 255），是否改为保持亮度见 #3。

## 安装

- **从 1.1 / 1.2 升级**：下载下方 `ColorGrabber-v1.3.apk` 直接覆盖安装，历史记录会保留。
- **从 1.0 升级**：1.1 起更换了签名密钥，需要先在历史页 ⋮ →「导出 CSV」备份数据，再卸载 1.0 后安装。已拍摄的照片保存在系统相册「ColorGrabber」文件夹中，卸载不会删除。

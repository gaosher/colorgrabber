## 新功能

针对 #9「白平衡的白色小框可以拖动吗」的建议：

- **参考白小框可以用手指拖动**（取景页参考白模式），范围限制在预览区域内；松手后位置会自动记住，下次打开不用重新拖。
- ⋮ 菜单新增「**参考白框恢复默认位置**」（仅在参考白模式下显示）。
- 每次拖动后会**重新确认参考白**（约 1 秒），避免拖动过程中误采。
- 小框离样品较远时，松手会弹出提示，状态栏也会标注「**离样品较远**」。

## 小框放在哪里最好

拖动本身不影响准确性（样品和参考白仍在同一帧里测量）；真正影响准确性的是小框**离样品多远**。补光通常中间亮、边缘暗，画面边缘本身也会偏暗，参考白读数偏暗或偏色时，样品读数也会跟着偏亮、偏色。

所以：**小框尽量放在试管旁边紧挨着的白背景上**，避开画面边缘、阴影和反光。

## 安装

- **从 1.1 / 1.2 / 1.3 升级**：下载下方 `ColorGrabber-v1.4.apk` 直接覆盖安装，历史记录会保留。
- **从 1.0 升级**：1.1 起更换了签名密钥，需要先在历史页 ⋮ →「导出 CSV」备份数据，再卸载 1.0 后安装。已拍摄的照片保存在系统相册「ColorGrabber」文件夹中，卸载不会删除。

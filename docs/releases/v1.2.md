## 新功能

针对 #5「点白校准应该取哪个点」的建议：

- **点白时自动检查白点质量**（取景页、测量页）：所选区域**过曝、偏暗或不均匀**时会弹出提示，并给出调整建议。提示只是提醒，校准仍然生效；建议按提示换一块区域重新点白。
- **测量页新增「推荐白点」按钮**：自动找画面中亮度高、颜色接近中性、均匀且不过曝的白色区域，**优先选靠近当前取色框的位置**（与样品受光更一致），并把取色框移过去。确认位置合适后，再点「点白校准」。找不到合适区域时会提示手动选取。

## 怎么选白点

1. 选**试管旁边**的白背景，与样品受光一致。
2. 只框**平整均匀**的白色，避开阴影、反光、试管壁和背景边缘。
3. **不要过曝**。
4. 取色框尽量大一些。

推荐用法：先把取色框大致放在试管附近 → 点「推荐白点」→ 确认位置 → 点「点白校准」。

## 安装

- **从 1.1 升级**：下载下方 `ColorGrabber-v1.2.apk` 直接覆盖安装，历史记录会保留。
- **从 1.0 升级**：1.1 起更换了签名密钥，需要先在历史页 ⋮ →「导出 CSV」备份数据，再卸载 1.0 后安装。已拍摄的照片保存在系统相册「ColorGrabber」文件夹中，卸载不会删除。
